# 해린이네 식탁

엄마·아빠·해린(48개월) 세 식구의 주간 식단 대시보드.

계성유치원 점심·간식과 메이플베어(월·수) 간식을 한 달 단위로 넣어두면, 매주 그날(과 다음 날) 유치원 메뉴와
주재료·요리 형태·맛이 겹치지 않는 집 식단과 장보기 목록을 만들어 준다.

## 화면

- **이번 주 식단·장보기**
  - 집에 있는 재료: 먼저 활용하고 장보기 목록에서 뺀다.
  - 사진으로 재고 확인: 냉장고·냉동실 사진을 올리면 재료·양·보관 위치를 찾아 목록으로 보여주고(불확실한 건 ?, 빨리 쓸 건 표시), 체크한 것을 집 재료에 넣는다.
  - 냉파 주간: 켜면 집 재료를 최대한 다 쓰는 식단과 최소 장보기 목록을 짠다(냉동 재료 해동 시점 포함). 주마다 따로 저장.
  - 만들 끼니 기본값: 아침 월–일, 점심 토·일, 간식 화·목·금(월·수는 메이플베어 간식), 저녁 월–금.
    표는 아침 → 점심 → 간식 → 저녁 순서. 평일 점심 칸은 '유치원 점심'으로 보이고 `+ 집 점심`(휴원·방학)으로 바꿀 수 있다(휴대폰에서는 빈 평일 점심 칸을 숨김).
    표에서 끼니마다 `외식·빼기`(메모 가능) / `+ 넣기`로 바꿀 수 있다.
  - 표 위 요일 버튼으로 하루만 본다(기본은 오늘, 다른 주는 월요일). `전체`를 누르면 일주일 표.
  - `다른 메뉴로`로 한 끼만 다시 짜고, `장보기 목록 다시 만들기`로 목록을 갱신한다.
  - 빈 끼니(외식에서 되돌린 끼니 등)는 `이 끼니만 짜기`로 한 끼만 채운다.
  - 도시락: 날짜 옆 `+ 도시락`으로 소풍·체험학습 날을 표시하면 그날 도시락 메뉴와 레시피를 짠다(그날 기관 점심은 겹침 대상에서 제외).
  - 재료가 새로 생겼어요: 선물·나눔 등으로 들어온 재료를 적으면 오늘 저녁 또는 내일부터 남은 끼니만 다시 짜고, 레시피와 장보기 목록도 갱신한다. 외식으로 빼둔 저녁을 집밥으로 되돌릴 수 있다.
  - 장보기 체크 표시는 저장되어 다른 기기에서도 보이고, `카톡용 복사`로 남은 품목만 복사한다.
- 끼니마다 `레시피`: 어른 2명 + 48개월 아이 1명(한 끼 약 2.5인분) 기준 재료 양, 순서, 해린이 몫 덜어내는 시점.
  식단을 짜면 하루 단위로 자동으로 써지고, 레시피 복사도 된다.
- **유치원 식단표 (월별)**: 식단표 사진이나 글을 넣고 `식단표 읽기` → 날짜별 표(직접 수정 가능).
- **우리 집 취향**: 해린·남편·엄마가 좋아하는/안 먹는 음식, 알레르기, 하루 요리 시간(기본 30분), 기타 요청.

## 구조

`index.html` 한 파일. claude.ai Artifact로 게시되어 아래 런타임 기능을 쓴다.

- `sample`: 식단표 읽기(이미지 포함), 주간 식단·장보기 생성, 한 끼 교체.
- `db`: `settings/family`(취향·집 재료), `months/YYYY-MM`(날짜별 유치원 메뉴), `weeks/YYYY-MM-DD`(월요일 기준 주간 식단·장보기·체크).

Artifact 밖에서 열면 저장은 브라우저 localStorage로 대체된다.

페이지에서 Claude를 바로 부를 수 없는 계정(`sample`이 없는 경우, 예: 무료 계정)은 'Claude 채팅 모드'로 동작한다.
AI 버튼을 누르면 같은 부탁 글을 보여주고, 사용자가 Claude 채팅에 붙여넣어(사진도 첨부) 받은 JSON 답을 다시 붙여넣으면 나머지 흐름은 그대로 진행된다.
이 모드에서는 레시피를 하루씩이 아니라 한 번에 요청한다.

## 다른 집용 버전 (`family/index.html`)

해린이네 정보를 뺀 공유용 페이지. '우리 가족·취향' 탭에서 어른 수와 아이별 정보(이름, 나이 살/개월, 다니는 곳,
방과후 간식 수업과 요일, 좋아하는/안 먹는 음식)를 입력한다.

- 아이들이 다른 기관에 다니면 '기관 식단표' 탭에서 기관(+방과후 수업)별로 식단표를 따로 넣는다.
  같은 기관·같은 수업에 다니는 형제는 식단표를 함께 쓴다.
- 식단은 아이별로 그날 먹은 메뉴와 겹치지 않게, 양과 아이 몫 손질은 나이별로 정한다.
- 집 간식은 방과후 간식 없이 집에 오는 아이가 있는 평일에 기본으로 켜진다.
- 데이터는 보는 사람 계정의 비공개 공간(`data/users/<id>/`)에 저장되므로 링크 하나를 여러 집이 써도 섞이지 않는다
  (같은 집 배우자와도 공유되지 않음). AI 기능은 각자의 Claude 계정 사용량을 쓴다.
- `index.html`(해린이네)과 코드가 갈라져 있으니, 공통 기능을 고칠 때는 두 파일을 함께 고친다.

## 해린이 한글 놀이 (`hangul/index.html`)

49개월 해린이용 한글 놀이. 인터넷 연결은 글꼴만 쓰고, 소리는 기기의 한국어 음성(읽어 주기)으로 낸다.

- **그림 짝꿍**: 글자(예: 나)를 듣고 그 글자로 시작하는 그림을 세 개 중에서 찾는다. 틀리면 그림 이름을 들려주고 다시 찾게 한다.
- **글자 블록**: 자음 + 모음을 눌러 글자를 만들고 소리를 듣는다. 그 글자로 시작하는 그림이 있으면 함께 보여준다.
- **손가락 쓰기**: 흐린 글자를 크레파스 색으로 따라 쓴다. 한 판은 글자 3개 + 이름 '해', '린'.
- **이름 찾기**: 친구·가족 이름을 듣고 이름 카드 2–3장 중에서 찾는다(한 판 5개). 소리가 안 나는 기기에서는 이름 글자를 함께 보여준다.
- **이름 기차**: 이름 글자를 차례로 눌러 기차 칸을 채운다(한 판 3개). 틀리면 다음 칸에 흐린 글자 힌트가 뜬다.
- 이름은 `어른` → '친구·가족 이름'에서 넣는다(한글 5자, 12명까지, 기본은 해린·엄마·아빠). 이 기기 localStorage에만 저장된다.
  이름 놀이가 끝나면 '다음에 만나면 이름 불러 주기', '이름 카드 만들어 선물하기' 같은 화면 밖 놀이를 알려준다.

### 다른 집용 버전 (`hangul/share/index.html`)

처음 열면 아이 이름을 묻고, 인사·손가락 쓰기 이름 글자·이름 놀이에 그 이름을 쓴다(어른 메뉴에서 바꿀 수 있음).
이름·설정·놀이 시간은 각자 기기에만 저장되므로 링크 하나를 여러 집이 써도 섞이지 않는다.
`hangul/index.html`을 고친 뒤 `hangul/make-share.sh`를 실행하면 같은 코드로 공유용 파일이 다시 만들어진다
(제목과 `PRESET_CHILD`만 다르다). 직접 고치지 말 것.

미디어의 나쁜 면을 뺀 설계:
- 광고·결제·외부 링크·추천 영상 없음. 점수·순위·연속 출석 보상·깜빡임·효과음 없음.
- 한 판은 5개로 끝나고 다음 판이 저절로 시작되지 않는다. 판이 끝나면 화면 밖에서 함께 할 놀이를 하나 알려준다.
- 하루 놀이 시간(기본 15분)이 지나면 하늘의 해가 지고, 하던 문제만 마친 뒤 쉬는 화면으로 넘어간다.
- `어른` 버튼(덧셈 확인)으로 시간·목소리 설정, 5분 더 주기. 시간과 설정은 그 기기 localStorage에만 저장된다.
- 첫 화면 `소리 확인`: 읽어 주기가 시작되는지 확인하고, 안 되면 원인(앱 안 화면, 무음 모드, 한국어 음성 없음)과 해결법을 보여준다.
  놀이 중 첫 소리가 안 나면 위에 같은 안내가 뜬다.
