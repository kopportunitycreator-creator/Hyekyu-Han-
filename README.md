# 해린이네 식탁

엄마·아빠·해린(48개월) 세 식구의 주간 식단 대시보드.

계성유치원 점심·간식과 메이플베어(월·수) 간식을 한 달 단위로 넣어두면, 매주 그날(과 다음 날) 유치원 메뉴와
주재료·요리 형태·맛이 겹치지 않는 집 식단과 장보기 목록을 만들어 준다.

## 화면

- **이번 주 식단·장보기**
  - 집에 있는 재료: 먼저 활용하고 장보기 목록에서 뺀다.
  - 만들 끼니 기본값: 아침 월–일, 간식 화·목·금(월·수는 메이플베어 간식), 저녁 월–금.
    표에서 끼니마다 `외식·빼기`(메모 가능) / `+ 넣기`로 바꿀 수 있다.
  - `다른 메뉴로`로 한 끼만 다시 짜고, `장보기 목록 다시 만들기`로 목록을 갱신한다.
  - 장보기 체크 표시는 저장되어 다른 기기에서도 보이고, `카톡용 복사`로 남은 품목만 복사한다.
- 끼니마다 `레시피`: 어른 2명 + 48개월 아이 1명(한 끼 약 2.5인분) 기준 재료 양, 순서, 해린이 몫 덜어내는 시점.
  식단을 짜면 하루 단위로 자동으로 써지고, 레시피 복사도 된다.
- **유치원 식단표 (월별)**: 식단표 사진이나 글을 넣고 `식단표 읽기` → 날짜별 표(직접 수정 가능).
- **우리 집 취향**: 해린·남편·엄마가 좋아하는/안 먹는 음식, 알레르기, 하루 요리 시간(기본 30분), 기타 요청.

## 구조

`index.html` 한 파일. claude.ai Artifact로 게시되어 아래 런타임 기능을 쓴다.

- `sample`: 식단표 읽기(이미지 포함), 주간 식단·장보기 생성, 한 끼 교체.
- `db`: `settings/family`(취향·집 재료), `months/YYYY-MM`(날짜별 유치원 메뉴), `weeks/YYYY-MM-DD`(월요일 기준 주간 식단·장보기·체크).

Artifact 밖에서 열면 저장은 브라우저 localStorage로 대체되고, 식단 생성 버튼은 비활성화된다.

## 다른 집용 버전 (`family/index.html`)

해린이네 정보를 뺀 공유용 페이지. 가족 구성, 유치원 이름, 방과후 간식 수업과 요일을 '우리 가족·취향' 탭에서 입력한다.
데이터는 보는 사람 계정의 비공개 공간(`data/users/<id>/`)에 저장되므로 링크 하나를 여러 집이 써도 섞이지 않는다
(같은 집 배우자와도 공유되지 않음). AI 기능은 각자의 Claude 계정 사용량을 쓴다.

`index.html`을 고친 뒤 `python3 scripts/make_family.py index.html family/index.html`로 다시 만들고,
생성 후 덧붙인 수정(설정 변경 시 라벨 갱신)은 스크립트에 반영되어 있지 않으니 함께 확인한다.
